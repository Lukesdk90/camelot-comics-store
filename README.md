Camelot Comics Store
📚 Descripción

Camelot Comics Store es una página web desarrollada para una tienda ficticia dedicada a la venta de cómics, videojuegos y productos relacionados con la cultura geek.

El proyecto fue realizado utilizando HTML5 y CSS3, aplicando una estructura semántica, diseño responsive y diferentes técnicas de organización del contenido.

🎯 Objetivo

El objetivo del proyecto es crear una página web moderna, funcional y adaptable a diferentes dispositivos, incorporando los principales conceptos aprendidos durante el curso.

🛠️ Tecnologías utilizadas
HTML5
CSS3
Flexbox
CSS Grid
Media Queries
Google Fonts
Formspree
GitHub Pages
📌 Características

La página incluye:

Página principal con presentación de la tienda.
Menú de navegación interno.
Sección de productos.
Cards de productos organizadas mediante Flexbox.
Sección de reseñas organizada mediante CSS Grid.
Formulario de contacto funcional mediante Formspree.
Contenido multimedia mediante un video embebido.
Diseño responsive para computadoras, tablets y celulares.
Google Fonts.
Diferentes fondos y estilos visuales.
Footer con información de la tienda.

📱 Diseño responsive

El sitio utiliza Media Queries para adaptar su contenido a diferentes tamaños de pantalla.

En dispositivos pequeños, el menú, las cards de productos, las reseñas y el formulario se reorganizan para facilitar la navegación.

📩 Formulario de contacto

El formulario utiliza Formspree para gestionar el envío de los datos ingresados por los usuarios.

El formulario cuenta con los siguientes campos:

Nombre
Correo electrónico
Mensaje
